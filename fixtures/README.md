# 本地 PPTX 样本

此目录用于放置仅供本地验证的真实 `.pptx` 语料。真实样本可能含敏感、保密或受版权限制的内容，因此 PPTX、打包文件以及记录真实文件名的本地清单均由 Git 忽略，不得提交或上传到 Issue。

## 所需覆盖

本地语料集应共同覆盖以下场景：

- 图表型页：关键信息主要位于图中，文本可能只有标题；
- 演讲者备注；
- 30 页以上的长文档；
- 若可获得，隐藏页和复杂表格。

当前本地语料已覆盖图表型页、演讲者备注和长文档。尚未检测到隐藏页；虽检测到表格元素，但复杂度仍需在渲染验证时确认。

## 本地清单

用被 Git 忽略的 `README.local.md` 记录每份真实样本的文件名、代表场景和结构统计。新增或替换样本时同步更新本地清单，但不得将真实文件名、内容主题或来源信息复制到公开文件和 Issue。

每份样本在进入此目录前都必须确认：

1. 仅在授权的本地环境中使用；
2. 不包含未经授权的个人信息或内部机密；
3. 不会因测试、日志或失败产物被上传到远端；
4. 如需公开或共享，先改用公开样本或完成脱敏与授权审查。

压缩包若只是目录中 PPTX 的重复副本，不作为独立覆盖样本。
