# 逐页策展工作台原型

- **范围 / 模式**：一次性桌面 Web 原型；Operate。
- **用户与任务**：熟悉材料的内部策展人员在 1440px 桌面上连续逐页核对标准页与 AnyDoc 文字、图片源文件；只有来源不足时才画框截图并标注，随后作出审核结论。1280px 仍须可用，移动端不在本票范围内。
- **已选视觉方向**：样片审看室。中性监看器黑承载来源页，明亮场记日志承载编辑；选择用 teal、待确认用 amber、排除用 red，并始终辅以文字或图形。
- **已批准构图**：[页列、画面与纵向日志](../mocks/review-workbench-option-c.webp)。左侧约 14% 为页队列，中间约 56% 为标准页渲染，右侧约 30% 为 AnyDoc 来源审核、可选截图日志与审核闸门，底部只保留键盘命令。
- **记忆点**：右侧先像来源清单一样逐项呈现 AnyDoc 文字与原始图片文件；来源审核完成后才解锁页面上的编号截图框，并与右侧同编号截图日志同步焦点。
- **约束**：真实样本与渲染只留本地；公开原型使用合成页，并允许从本机载入私有 PNG 做计时走查。状态不能只靠颜色。approved / excluded 先重新打开才能编辑。

## 构图与媒介清单

| 可见要素 | 构图承诺 | 实现媒介 |
| --- | --- | --- |
| 顶部状态条 | 文档、页码、会话计时、全局日志与帮助保持单行 | HTML/CSS |
| 左侧页队列 | 6 个紧凑缩略项，明确继承、变化、pending、approved、excluded；支持页码直达 | HTML/CSS；公开合成缩略页 |
| 中央来源页 | 工作面最大区域；初始无框，来源审核完成后才允许拖拽创建编号截图框 | HTML/CSS/SVG；本地文件载入可替换合成页 |
| 右侧 AnyDoc 来源 | 默认页签；文字提取可修订确认，图片源文件逐项展示文件名、格式、尺寸、预览和保留/忽略处置 | HTML/CSS |
| 右侧按需截图 | 第二页签；零截图为空态，人工画框后按编号编辑 summary、类型、顺序和 VLM 草稿 | HTML/CSS |
| 审核闸门 | 集中列出硬阻塞与质量提示；批准、排除、重新打开保持显式 | HTML/CSS |
| 底部命令条 | A/X/R、方向键与保存提示始终可见，输入聚焦时不劫持按键 | HTML/CSS |
| 构图稿 | 只作为视觉依据，不进入运行时，也不栅格化核心 UI | 生成的 WebP；完整 prompt 已嵌入 sidecar |

## 尚待原型验证

- 页队列宽度在 1280px 是否仍能保护来源页可读面积。
- 来源清单与可选截图分两阶段是否减少不必要的画框操作。
- 批准后自动前进、继承页默认隐藏，以及硬阻塞提示是否符合策展人员节奏。
- 使用本地真实页完成全流程时的每页总耗时。
