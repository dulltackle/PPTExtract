# 页对应工作面

- **范围 / 模式**：版本专属全屏 React 工作面；Operate。1440px 为主，1280px 保持三栏与证据可读性；移动端不在初版范围。
- **用户与任务**：摄取操作者或策展人员逐项消解重复指纹、SlideID 冲突和多候选，把新版本源页明确对应到历史页或新身份。
- **已确认方向**：延续“样片审看室”。左侧是 case 队列，中央同步并置新版本源页与当前历史候选，右侧在冷灰场记纸上记录身份决定；底部持续呈现保存和版本门禁。
- **真实性边界**：旧当前版本在最终确认前继续服务；逐项决定显式保存且可修改；最后一项不会自动启用版本；最终确认原子检查并冻结对应关系。
- **并发语义**：每次保存携带 ETag / If-Match。412 后保留本地未保存选择、重载服务器决定并并排比较，绝不自动重试覆盖。

## 方向契约

- **THESIS**：页身份不是算法推断，而是一组可对照证据支持下的人类决定；证据、候选与后果必须同时在场。
- **FIRST VIEWPORT**：顶栏直接说明版本、剩余 case 与旧版本服务状态；下方三栏贯穿剩余高度，中央两张标准页渲染结果获得最大可读面积。
- **KEY STATES**：首次加载、无候选、未决定、本地草稿、保存中、已保存、候选占用、证据失败、412 并发冲突、版本状态变化、最终检查失败、确认中与成功。
- **KEYBOARD**：队列和候选使用标准列表与单选语义；`Ctrl/⌘ + Enter` 在非输入焦点保存并前进；未保存选择离开时提示。
- **FINAL REVIEW**：汇总沿用未变、沿用变化、新身份、软删除，以及未决/冲突/证据失败；明确冻结后纠错只能作废并重新摄取。
