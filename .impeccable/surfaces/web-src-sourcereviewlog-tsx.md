# 来源文字核对稿

## 范围与模式

- 适用于 React 策展工作台右侧来源日志中的标题与正文核对路径。
- 界面模式为 Operate：高密度、键盘可达、以完成核对和修订为目标。
- 不改变备注、表格、图片、捕获记录与最终决策等其他区域。

## 已确认方向

- 延续“样片审看室”视觉系统：深色监看台承载浅色稿纸，青色表示当前操作，琥珀色表示待处理。
- 标题在前、正文在后，采用无卡片的连续核对稿；以 1 个标题、11 个正文块和长文本作为压力基线。
- 编号轨道始终可见且弱化：标题使用“标题 1”，正文使用“正文 01”起的稳定编号。
- 全文自然换行，不截断、不折叠、不摘要、不合并、不重排；空块仍保留身份。
- 主文字可点击，另提供语义化编辑按钮；任一时刻最多一个原位编辑器，多块修改累计到页级草稿。
- Escape 只恢复打开当前编辑器时的草稿基线；Tab 和 Enter 保持原生键盘行为。
- 仅修改后的块显示“已修改”并允许查看原始提取；未修改块不重复展示原文。
- 已确认内容默认只读，必须经“修改文字”边界并明确提示会使既有确认失效后才能再次编辑。
- 1280 宽度维持三栏工作台；模拟 200% 文字缩放时三栏保留工作区内部横向滚动，核对块改单列且页面无横向溢出。
