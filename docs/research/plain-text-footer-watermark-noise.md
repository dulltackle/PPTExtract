# 普通文本框页脚与水印噪声的本地样本调查

## 决议建议

**初版不增加普通文本框噪声的自动删除，也不把启发式候选直接移出 Chunk 正文。** 当前 5 份代表性样本共 200 页，没有发现普通文本框形成的重复页脚或水印；跨页精确重复的普通文本只有 3 组，人工核对后全部是有意义的页内标签。只按“重复”删除会发生真实误删，而本样本又没有正例可用于验证页脚规则的精确率。

初版应明确区分三件事：

1. **自动删除：不做。** 除 anydoc 已按 OOXML 占位符类型过滤的 `ftr`、`sldNum`、`dt` 外，普通文本框一律先作为来源内容保留。
2. **候选识别：可延后，不作为初版发布硬依赖。** 若为了降低人工操作成本而提前实现，只能生成待确认候选，不能改变正文或审核状态；下面的“最小安全规则”只是本次探索阈值，不是已经验证的分类器。
3. **保留到 metadata：只在人工确认后发生。** 策展人员把某个来源文本单元确认为重复页脚噪声后，该单元才从 Chunk 正文中排除，并把噪声文本、原始来源引用、影响页、确认人、确认时间和规则版本保留在 metadata。选择“保留为内容”时不得做任何移除。

这与地图既定前提“可靠识别出的重复页脚噪声进 metadata”一致：本调查把“可靠”收紧为**人工确认**，而不是启发式阈值命中。

## 范围与隐私边界

- 样本：仓库本地、被 Git 忽略的 5 份真实 `.pptx`，合计 200 页；覆盖情况以 [`fixtures/README.md`](../../fixtures/README.md) 为准。
- 报告和脚本只保留匿名文档编号、聚合数量、位置类别和长度区间；不保存或输出真实文件名、原文、主题或来源，也不上传样本。
- 调查对象是**页上实际存在的普通文本形状**。母版/版式上的非占位符装饰、图片水印、视觉上存在但没有文本节点的图形不在本票问题的“普通文本框”范围内。
- 本地样本没有隐藏页；这一限制不影响普通文本框统计，但意味着结论不能外推到隐藏页的内容策略。

## 方法

### 单页 AnyDoc 输出

可复现实验脚本为 [`scripts/research/analyze_pptx_footer_noise.py`](../../scripts/research/analyze_pptx_footer_noise.py)。环境锁定 `firecrawl-anydoc==0.1.8`，与现有 AnyDoc 研究及 ADR-0003 的依赖基线一致。

每一页的调用过程如下：

1. 按 `presentation.xml` 的 `p:sldIdLst` 顺序枚举页；
2. 把 `sldIdLst` 收窄到单页，保留该页的 OPC 关系闭包以及演示级入口；不把样本写到仓库；
3. 调用 `anydoc.to_document(projected_bytes, format="pptx")`；
4. 递归读取普通文本形状（包括组合图形内文本），以 Unicode NFKC + 空白折叠得到用于比较的文本单元；
5. 统计同一文档内的精确重复页数、归一化几何位置、页面区域和 AnyDoc 模型是否保留该单元。

AnyDoc 的 PPTX frontend 会跳过 `ftr`、`sldNum`、`dt` 占位符，但会把视觉上像页脚的普通文本框当普通形状处理；这是锁定 v0.1.8 源码和合成样本共同确认的现有事实，详见 [`anydoc-pptx-output.md`](./anydoc-pptx-output.md#3c-母版页脚等每页重复的噪声) 及上游 [`src/formats/pptx/mod.rs`](https://github.com/firecrawl/anydoc/blob/v0.1.8/src/formats/pptx/mod.rs#L390-L394)。本次真实样本的页级形状中没有带非空文本的这三类标准噪声占位符，因此“真实样本下占位符过滤效果”没有新增正例；占位符行为仍以既有源码与合成实验为证据。

### 探索性阈值

为了检验“如果现在加规则，会命中什么”，脚本计算两档候选：

- **宽候选**：同一归一化文本至少出现在 `max(3, ceil(页数 × 20%))` 页，且文本框的上、左、宽、高在各页的偏差分别不超过页面尺寸的 2%。
- **严格页脚候选**：满足宽候选，同时位于页面底部区域、至少出现在 `max(5, ceil(页数 × 50%))` 页、长度不超过 40 个字符。

这些阈值没有正例训练或独立评测集支撑，**只能作为探索性候选生成规则，不能作为真值，更不能触发自动删除**。

AnyDoc 保留性检查使用归一化文本对单页 `Document` 递归展开后的文本做 exact-substring 匹配。它会受 AnyDoc 分块、富文本拆分和归一化差异影响；短文本还可能偶然成为别的长文本子串。因此该指标只用于保守确认“明确找到”，不能把“未找到”解释为 AnyDoc 一定过滤，也不能据此决定删除。

## 聚合结果

| 指标 | 结果 |
| --- | ---: |
| 文档 / 页 | 5 / 200 |
| 单页 AnyDoc 转换成功 / 失败 | 200 / 0 |
| 不同普通文本单元 | 595 |
| 至少跨 2 页精确重复的文本组 | 3 组，7 页次 |
| 至少跨 3 页精确重复的文本组 | 1 组，3 页次 |
| 位置稳定的重复文本组（2% 阈值） | 0 |
| 宽候选 | 0 |
| 严格页脚候选 | 0 |
| 普通文本框页脚 / 水印正例 | 0 / 0 |

3 组重复文本全部位于页面中部，均为 1–12 字符的短单元，位置随页面变化。保守的 AnyDoc exact-substring 检查确认其中 2 组在各自出现页均被完整找到；另一组不能据此判断为被过滤，原因见上节指标限制。

在不记录原文的前提下逐组查看来源页与标准页位置后，人工分类如下：

| 人工分类 | 文本组 | 页次 | 脱敏模式示例 |
| --- | ---: | ---: | --- |
| 确认为重复页脚 | 0 | 0 | 无 |
| 确认为水印 | 0 | 0 | 无 |
| 合法重复正文或标签 | 3 | 7 | 两组为相邻页中的短序号标签；一组为 3 页中的短字段标签，后接各页不同内容 |
| 因重复整页而重复 | 0 | 0 | 无；上述 3 组均不是由相同页文本整体复制产生 |
| 不确定 | 0 | 0 | 无 |

**关键证据：**

- “普通文本框重复噪声在当前代表集中的观测发生率为 0/200 页”来自本地可复现实验与逐组人工核对；这是当前样本事实，不是对未来语料的零风险保证。
- “仅按重复会误删”有 3/3 组实际反例：所有跨页精确重复单元都仍承担页内语义。它直接否定“重复若干次即删除”的规则。
- “AnyDoc 不会识别视觉意义上的普通文本框页脚”来自 v0.1.8 一手源码；真实样本没有正例，因此本调查没有测出其在本语料中的实际漏滤率。

## 误删风险

1. **字段标签和结构标签会重复。** 观测到的唯一 3 页重复组就是字段标签；删除后，各页后续内容失去语义引导。
2. **序号、图例和流程节点天然短且重复。** 两组相邻页短序号已经满足最宽松的“出现两次”条件，却不是页脚。短文本、数字或低信息量都不能单独充当删除依据。
3. **模板位置不是语义。** 相同模板可把字段标签固定在近似位置；位置稳定最多提高候选置信度，不能证明它是噪声。
4. **跨版本继承会放大错误。** 若自动删除进入页的规范来源内容或指纹输入，错误可能随相同页指纹继承；这与 ADR-0001 的人工质量闸门及 ADR-0002 的免重审目标冲突。
5. **样本没有正例，无法估计召回率或正例精确率。** 对 0 个页脚/水印正例调阈值，只能说明本轮没误命中，不能证明规则能识别未来页脚。

## 最小安全规则与人工兜底

如果后续新语料确实出现明显普通文本框页脚，可把以下规则作为**候选生成起点**：

- 只比较同一文档版本内、非占位符的文本单元；先做 NFKC 和空白折叠，只接受精确文本相等；
- 同时要求：页面底部、几何位置偏差不超过 2%、覆盖至少 50% 且不少于 5 页、长度不超过 40 字符；
- 标题、正文占位符、表格单元格、演讲者备注、图片 alt text 和页面中部文本不得进入该规则；
- 命中结果只显示为“疑似重复页脚”，不得自动从正文删除、自动批准页面或改变页指纹；
- 策展人员必须在标准页渲染结果上看到候选位置、影响页数和若干相邻页，选择“确认为噪声”或“保留为内容”；
- 只有“确认为噪声”才批量应用到**文本和几何签名都一致**的页，把来源单元从 Chunk 正文排除并写入 metadata；任何文字或位置变化都产生新候选；
- 保存确认人、时间、候选规则版本、来源单元引用、影响页清单和撤销记录。重新判断为内容时恢复正文并触发正常重审。

人工兜底不是临时例外，而是初版唯一可靠的普通文本框噪声判定。若初版不实现候选检测，审核工作台仍应允许策展人员在来源文本单元上手工执行同一“确认为重复页脚噪声”动作；数据契约应先容纳 metadata 和审计信息，检测器以后只是减少点击，不改变判定权。

## 限制与后续触发条件

- 5 份、200 页是代表性本地样本，不足以给跨组织、跨模板语料估计总体发生率。
- 本次只检验精确重复普通文本；逐页变化的页码、日期、版本号需要类型化模式，但这种模糊匹配误删风险更高，在出现真实正例前不应加入。
- 图片水印、母版图形和渲染后才可见的装饰需另用标准页渲染或 OOXML 母版审计评估，不应混入文本规则。
- 当新增样本首次出现人工确认的普通文本框页脚/水印，或人工手工标记累计到足够正反例时，再建立独立评测集，报告候选级 precision/recall 后决定是否默认开启候选检测。

## 复现

```bash
python3 -m pip install --target /tmp/pptextract-anydoc-v018 firecrawl-anydoc==0.1.8
python3 -m py_compile scripts/research/analyze_pptx_footer_noise.py
PYTHONPATH=/tmp/pptextract-anydoc-v018 python3 scripts/research/analyze_pptx_footer_noise.py fixtures
```

成功输出必须满足：`documents = 5`、`pages = 200`、`conversion_failures = 0`，且 JSON 中不出现真实文件名或任何原文。脚本输出的匿名编号只用于同一次运行内分组，不承担稳定样本身份。
