# AnyDoc 来源图片按引用处置并原样交付

AnyDoc 会把页内图片暴露为有顺序的引用，而同一二进制对象可能在一页或多页被重复引用。我们决定为每个页版本的每个引用分别建立来源图片引用、人工处置与审计；相同 SHA-256 只形成重复提示和存储去重，不合并业务决定。被纳入的来源图片以 AnyDoc 提供的原始字节和媒体类型直接成为视觉资产，不经过标准页渲染、裁剪、转码、缩放或重采样；标准页渲染只用于人工对照，并继续作为人工补充截图资产的裁剪基准。

这一边界优先保留来源证据与可验证性，而不是把全部资产统一成 PNG。产物清单必须为每项资产记录来源、媒体类型、字节数、SHA-256 与字节契约；来源图片使用 `anydoc_original`，人工截图使用 `standard_render_crop`。渲染配置变化只能使标准页渲染和人工截图资产失效，不得改变已冻结的 AnyDoc 来源图片资产。
