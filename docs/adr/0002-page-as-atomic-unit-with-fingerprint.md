# 以页为原子单位，用页指纹实现幂等与审核继承

系统长期运行并接收同一文档的反复上传，而人工策展的成本很高（见 ADR-0001），因此绝不能让人重审内容未变的页。我们选择页作为寻址、审核、幂等判定与导出的统一单位，并以「页文本 + 页内图片字节的联合哈希」作为页指纹：指纹未变则继承既有标注与审核状态，指纹变化则退回待审并以旧标注预填。

页指纹不能从 anydoc 对整份文档产生的扁平输出中事后恢复；它由 ADR-0003 确立的页投影与转换适配层逐页计算。规范输入带 `fingerprint_version`，包含确定性序列化的页来源内容，以及按引用顺序和重复次数纳入的图片字节哈希。转换器升级若改变规范内容语义，必须提升指纹版本并显式处理重审，不得让旧审核静默继承。

## Considered Options

仅对页文本取哈希会漏掉「文字没动但图换了」的情况，而这在图表型语料中恰恰是主要的变更形式；对渲染图取像素哈希最忠实，但渲染结果不具确定性，会造成大量假重审，直接吞掉人工工时。
